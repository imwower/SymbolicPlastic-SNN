# SymbolicPlastic-SNN

符号突触 + 结构可塑性的大规模脉冲网络（无梯度训练）

## 概述

目标：在不使用实值权重或偏置、仅依赖连接的存在与符号（±1）、阈值与不应期的前提下，实现可扩展、稳定、可训练（无反向梯度）的脉冲神经网络。关键思路是用距离驱动的随机连边形成“小世界 / 层级模块化”拓扑；用生长‑剪枝‑稳态的结构可塑性（STDP 式“开关”、老化剪枝、奖励门控）来学习；并通过入度恒定 + E/I 平衡 + 多延迟以及阈值 / 不应期来保证稳定与可分性。

### 1. 核心特性

- **仅符号突触**：每条边只有符号 $a_{ij} \in \{-1, +1\}$（兴奋 / 抑制），没有可学习幅值，也没有偏置项。
- **阈值 + 不应期**：每个神经元使用固定阈值 $\theta$ 与不应期 $\tau_{\text{ref}}$ 作为稳定器与节流阀。
- **距离驱动连边**：连边概率随几何距离与层间距离衰减，并混入少量长程桥接边，得到小世界拓扑。
- **从零连边冷启动**：使用低率背景噪声或短时“老师驱动”点燃活动，然后完全靠结构规则学习。
- **结构可塑性**：在线增删边、翻转符号，维持入度近恒定与 E/I 平衡。
- **多延迟表达**：通过不同延迟的并行边表达时间模式，而非叠加多条同延迟的兴奋边来等价权重。
- **事件驱动实现**：稀疏邻接（CSR/CSC）配合事件驱动更新，适合大规模与能效受限场景。

### 2. 快速开始

- **设定尺度**：定义层 / 模块划分；为每个神经元赋予坐标 $\mathbf{r}_i$ 与层索引 $\ell_i$；选择目标入度 $K$（推荐 64–256）与 E/I 比约 1:1（±10%）。
- **时间常数**：$\Delta t = 1\ \mathrm{ms}$，$\tau_m = 20\sim 50\ \mathrm{ms}$，泄漏系数 $\lambda = \exp(-\Delta t / \tau_m)$。
- **阈值 / 不应期**：按第 6 节“σ 法则”计算 $\theta$；$\tau_{\text{ref}}=2\sim 5\ \mathrm{ms}$ 为起点。
- **初始化**：从 0 连边出发；用距离衰减 + 0.5%–2% 长程采样候选边；注入每神经元 0.1–1 Hz 的泊松噪声以点火。
- **在线学习循环**：每 200–1000 步执行老化剪枝 + 距离加权再生长 + STDP 式符号开关，保持每个神经元入度近似 $K$。
- **读出**：在输出层或外部读出器采用 WTA / 计数簇或感知机规则做决策。
- **监控**：跟踪平均放电率 $\bar{r}$、分枝因子 $b$、互相关 / 雪崩统计；若异常，优先调整结构或 $\tau_{\text{ref}}$，最后再微调 $\theta$。

### 3. 数学模型

**状态变量**：膜电位 $v_i$、脉冲指示 $s_i \in \{0,1\}$、不应期计时 $r_i$。

**离散 LIF + 不应期**

$$
v_i(t+1) =
\begin{cases}
v_{\text{reset}}, & r_i(t) > 0 \\
\lambda v_i(t) + \sum_j a_{ij}\, s_j(t - d_{ij}), & r_i(t) = 0
\end{cases}
$$

$$
s_i(t) = \mathbf{1}\{ v_i(t) \ge \theta \}, \qquad
r_i(t+1) =
\begin{cases}
\tau_{\text{ref}}, & s_i(t) = 1 \\
\max(0, r_i(t) - 1), & s_i(t) = 0
\end{cases}
$$

若 $s_i(t)=1$，则立即执行 $v_i(t+1)\leftarrow v_{\text{reset}}$、$r_i(t+1)\leftarrow \tau_{\text{ref}}$。

**延迟**：$d_{ij}$ 与空间距离一致（见第 4 节），可加入少量抖动提升异步性。

**读出**：在时间窗内计数 / 统计最早放电时间，配合侧抑制（WTA）。

### 4. 拓扑与初始化（从 0 连边出发）

- **混合距离度量**：$\delta(i,j) = \lVert \mathbf{r}_i - \mathbf{r}_j \rVert_2 + \alpha \lvert \ell_i - \ell_j \rvert$。
- **生长概率（候选库）**：$p_{\text{add}}(i \rightarrow j) = \kappa \exp(-\delta / \sigma) + \rho_{\text{LR}}$，其中 $\sigma$ 控制局部半径，$\rho_{\text{LR}} = 0.5\%\sim 2\%$ 表示长程注入。
- **入度恒定**：每个神经元目标入度 $K$，更新后投影回 $K \pm 1$。
- **E/I 平衡**：±1 幅值对称，建议输入数量约 1:1（或轻微抑制偏置）。
- **冷启动激活**：泊松噪声 0.1–1 Hz / 神经元或短时任务驱动脉冲。

### 5. 无梯度学习：生长‑剪枝‑稳态

1. **STDP 式“开关”规则**（本地、在线）  
   - pre 在 post 之前（$\Delta t>0$ 小窗内）：鼓励兴奋边存在或翻转为 +1。  
   - post 在 pre 之前：抑制兴奋（翻为 −1 或移除兴奋边）。  
   - 长期不相关：老化计数低的边优先被剪。

2. **奖励门控（可选）**  
   使用任务级奖励 $R$ 门控生长 / 保留阈值，表现更好的结构更易保留。

3. **结构进化 / 重连（低频）**  
   周期性重连低介数或诱发振荡的子图，维持小世界与可控谱半径。

**生长‑剪枝流程（每 200–1000 步）**

1. 统计边相关 / 使用计数 $C_{ij}$ 与放电率 $r_i$。  
2. 按 $C_{ij}$ 分位剪掉最弱约 10% 入边（保持 E/I）。  
3. 用 $p_{\text{add}}$ + 局部相关得分补齐到入度 $K$。  
4. 执行互连合规（见第 7 节）。

### 6. 阈值 θ 与不应期 τ_ref 的设定

#### 6.1 θ 的“σ 法则”

有效记忆窗 $W_{\text{eff}} \approx 1 / (1 - \lambda)$。若每个输入一步内放电概率 $p = r_{\text{pre}}\Delta t$，则净输入标准差

$$
\sigma_I \approx \sqrt{K \cdot p (1 - p) \cdot W_{\text{eff}}}.
$$

阈值设定为 $\theta = \beta \sigma_I$，其中 $\beta \in [1.5, 3]$。直观地，$\theta$ 取输入噪声的 1.5–3 σ，只有相关同步输入到来时才触发。

**示例**：$\Delta t = 1\ \mathrm{ms}$，$\tau_m = 50\ \mathrm{ms}$ ⇒ $\lambda \approx 0.98$，$W_{\text{eff}} \approx 50$；$K = 128$，$r_{\text{pre}} = 5\ \mathrm{Hz}$ ⇒ $p = 0.005$；$\sigma_I \approx 5.64$；取 $\beta = 2$ 得 $\theta \approx 11.3$（实现时可取整数 11）。

#### 6.2 不应期 τ_ref

- 常用范围：2–5 ms；若出现同步爆发或短环自激，增至 5–10 ms。
- 约束：$\tau_{\text{ref}} \ge d_{\min}(E \leftrightarrow E)$，若允许双向兴奋需保证最短延迟覆盖不应期。
- 优先用 $\tau_{\text{ref}}$ 控制放电率与爆发，再微调 $\theta$。

### 7. 互连与“多条连接”的安全约束

- **避免短延迟 E↔E 自激**：若允许双向兴奋，要求最短延迟 $\ge \tau_{\text{ref}}$，或直接令其中一侧为抑制（Dale 约束）。
- **多条连接 ≠ 放大权重**：允许不同延迟的并行边表达时间图样；合并同一对节点且“相同延迟 + 相同符号”的并行边。
- **距离‑延迟一致性**：$d_{ij} \approx \text{round}(\lVert \mathbf{r}_i - \mathbf{r}_j \rVert / v)$ + 少量抖动。

### 8. 读出与任务驱动（仍可无梯度）

- **无监督**：按时间窗统计脉冲计数 → 聚类 / 原型最近邻；模块内加侧抑制（WTA）。
- **监督但不反传**：  
  - 用感知机规则训练只读出层（从上游脉冲计数到类别的线性阈值器）。  
  - 奖励门控结构学习：预测正确则冻结或鼓励兴奋，错误则剪兴奋增抑制。
- **全网无梯度**：先用第 5 节的自组织得到可分表征，再用投票器 / WTA 读出。

### 9. 规模化实现与资源估算

- **数据结构**：稀疏邻接（CSR/CSC）；每条边建议存储目标索引 (4 B) + 符号 (1 bit / 1 B) + 延迟 (1 B) + 对齐 ≈ 8 B / 边。
- **事件驱动成本**：计算复杂度与活动边数成正比，放电率越低越省。
- **内存示例**：  
  - $N = 10^6$, $K = 128$ ⇒ $M = 1.28 \times 10^8$ 边 ⇒ 约 0.95 GiB。  
  - $N = 10^5$, $K = 64$ ⇒ $M = 6.4 \times 10^6$ 边 ⇒ 约 48.8 MiB。
- **并行实现**：按空间 tile / 层模块切分；边界使用事件队列交换；延迟队列批处理。

### 10. 监控与调参闭环

优先跟踪三类指标：

1. **平均放电率 $\bar{r}$**：目标 1–10 Hz（任务相关可调）。
2. **分枝因子 $b$**：一次脉冲引发的后续脉冲数均值，理想 0.9–1.1（近临界）。
3. **互相关峰 / 雪崩尾**：若出现窄峰或重尾，先增 $\tau_{\text{ref}}$，再增 $\theta$，若仍异常则剪短延迟 E↔E、降低长程比例。

调参优先级：先改结构（E/I、入度、短环、长程占比）与 $\tau_{\text{ref}}$，最后再微调 $\theta$。

### 11. 参考伪代码

**步进与发放（事件驱动）**

```python
# 状态：v[i], ref[i], spike[i][t]
# 参数：theta, tau_ref, lambda_, v_reset = 0
# 结构：E_plus[i], E_minus[i] (元素为 (pre, delay))
active = seed_from_noise()  # 冷启动
for t in range(T):
    nxt = []
    for i in active:
        if ref[i] > 0:
            ref[i] -= 1
            v[i] = v_reset
            continue

        I = 0
        for (j, d) in E_plus[i]:
            if spike[j][t - d]:
                I += 1
        for (j, d) in E_minus[i]:
            if spike[j][t - d]:
                I -= 1

        v[i] = lambda_ * v[i] + I
        if v[i] >= theta:
            spike[i][t] = 1
            v[i] = v_reset
            ref[i] = tau_ref
            nxt.extend(out_neighbors[i])  # 事件驱动传播
    active = dedup(nxt)
```

**结构更新（每 `prune_interval` 步）**

```python
for i in neurons:
    prune_weakest_in_edges(i, quota=0.10)  # 1) 老化剪枝

    while indegree(i) < K:                 # 2) 再生长
        j = sample_by_distance_and_activity(i)
        if allowed_by_rules(i, j):
            add_edge(i, j, delay=dist2delay(i, j))

    for (j, _) in in_edges(i):             # 3) STDP 式“开关”
        if pre_before_post(j, i):
            encourage_exc(i, j)
        if post_before_pre(i, j):
            discourage_exc(i, j)
```

### 13. 常见问题（FAQ）

- **Q1：固定阈值会导致不同节点尺度不一致吗？**  
  A：通过入度近恒定、E/I 近平衡与泄露 / 不应期，大多数节点的输入尺度会落在同一量级；必要时可低频调整全局或分层尺度因子，或在结构更新中做“放电率门控剪枝 / 生长”。

- **Q2：从零连边如何“点燃”？**  
  A：注入低率泊松噪声（0.1–1 Hz / 神经元）或短时老师驱动序列，一旦网络形成有用局部回路即可关闭或大幅降低噪声。

- **Q3：出现同步爆发 / 雪崩怎么办？**  
  A：先把 $\tau_{\text{ref}}$ 提到 5–8 ms；剪短延迟的 E↔E 互连；提高抑制入度或降低长程比例；必要时略增 $\theta$。

- **Q4：精度不够怎么办？**  
  A：增加 $K$ 或引入多延迟集合（表达更丰富时间模式）；增加层 / 模块数与少量长程桥；在读出端使用 WTA + 侧抑制。

- **Q5：读出必须也无梯度吗？**  
  A：如果必须，全网可无梯度（WTA / 计数投票）；如果允许，在读出层使用感知机规则（仍无反传）通常能显著提高样本效率。

### 一句话总结

在“仅符号突触 + 阈值 + 不应期”的约束下，距离驱动的小世界拓扑配合无梯度的结构可塑性，完全可以支撑大规模、稳定、可学习的 SNN。抓住三件事：入度近恒定 + E/I 平衡 + 多延迟；用“σ 法则”定 $\theta$，把 $\tau_{\text{ref}}$ 设到盖住最短 E↔E 回路；按“生长‑剪枝‑稳态”循环在线更新结构，即可把系统在工程上跑稳、跑快、跑大。
